### 1. 每周选题工厂

链路：`定时 → AI 选题官（豆包） → 飞书消息推送`

AI 输出 5 个候选选题，每个含：标题（18–25 字）、分类、五维打分、依据一句话，末尾附「本周热点简报」。
消息带「打开选题池」按钮，直达 G1 终裁。

### 2. 每日 EJU 情报简报

由原来的「AI 行业新闻推送」模板改造，改为 EJU / 日本留学情报官。

关注优先级：JASSO 官方 → 各大学出愿 → 签证政策 → 社媒热议。
输出三段：今日速览（≤40 字）/ 值得关注（2–3 条，每条带「影响」与「可做内容」）/ 今日提醒。
硬性纪律：不编造日期、分数线、政策条文；无实质变化时宁可只输出速览 + 提醒。

### 因此联网能力这样补位

飞书 workflow 的 AI 节点**没有联网工具**，所以：

- **飞书 workflow**：生成**常青选题**（不依赖实时信息），prompt 已加「无联网时走常青模式」分支，并禁止编造时效信息
- **WorkBuddy 周一 09:00 自动化**（已验证可跑、有 WebSearch）：负责**联网检索实时热点** → 生成选题 → 写回选题池 → 飞书推送

两者分工：飞书管「定时提醒 + 常青选题」，WorkBuddy 管「联网热点」。

## 三、怎么立即跑一次看效果

因为 NO_REPEAT 无效，手动触发只能走 UI：

1. 打开 Base「EJU Pro 内容运营台」→ 右上角「自动化」/「流程」
2. 找到「每周选题工厂」→ 点运行（或编辑页的「测试运行」）
3. 约 30–60 秒后，飞书会收到「多维表格助手」发来的卡片消息

> 推送方是「多维表格助手」（`ou_3ee27e4f83ea834ddb8f63a7b0a78961`）。
> 首次推送后才会建立单聊会话，因此**打开飞书 App 就能看到消息**，不需要你在群里 @ 机器人。

## 四、踩过的坑（改配置时别再踩）

1. `+workflow-create` 必须带 `client_token`，否则报 minstringlength(1)
2. AI 节点的 `children.links` 要保留 `llm` / `memory` / `tool` 三个 slot，`tool.to` 可为空串
3. `+workflow-update` 是全量替换，省略 steps 会清空流程
4. update 后不会自动改变启用状态，需单独 `+workflow-enable`
5. 修改触发时间后建议 disable → enable 强制重新注册

## 五、git 推送（本机必配代理）

本机开了系统代理 `127.0.0.1:7890`，但 git 不自动读它，直连 GitHub 会报
`Empty reply from server` / `CONNECT tunnel failed 502`。已对本仓库配置：

```
git config --local http.proxy  http://127.0.0.1:7890
git config --local https.proxy http://127.0.0.1:7890
```

配置后 push 秒通（2026-10-24 已推送至 `feature/db-restructure`，最新 f365d57）。
