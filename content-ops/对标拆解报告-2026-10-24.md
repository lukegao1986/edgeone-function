## 二、拆解出的四条核心规律

**1. 赞粉比决定内容策略。** 工具型内容（清单/统计/避坑）赞粉比 >8，作品展示型 <2.5。想涨粉 → 只做可被收藏的工具内容。EJU Pro 的 44 份真题统计正是最强的工具型素材。

**2. 标题 7 公式（18–25 字，核心词前置 15 字内）：** 数字型 / 痛点直击 / 悬念反转 / 对比体 / 身份标签 / 情绪共鸣 / 干货承诺。factcheck 的标题上限已从 20 字修正为 25 字（有对标依据）。

**3. 留学赛道爆款五源：** 留学内幕、申请指南、低价留学、机构评测、留学生活。但「揭黑/情绪」类与教学方身份冲突——**只做信息差科普，不做情绪对立**。

**4. 人设五型：** 机构官方号 / 学姐学长号 / 中立测评号 / 创始人号 / 文书号。EJU Pro 适合「教师专业号 + 学员案例」双轨。

## 六、关于大模型 API 的结论

**当前不需要购买任何 API**：
- 选题发现与热点检索 → 飞书 workflow 内置豆包模型（免费）
- 内容生产（长文/笔记/口播/封面变量）→ 布克直接写
- 图集渲染 → 本机 Chrome headless（已验证零依赖）

**未来三个触发点，到了再买**：
1. n8n/Dify 装好后想跑全自动草案流水线 → DeepSeek（已有 DEEPSEEK_API_KEY）即可起步
2. 想上更高文字质量 → 建议 Claude API（约 $3/百万 token 输入）
3. 小红书数据回流 → 无 API 可买，唯一合规路径是专业号数据中心人工导出（升专业号是 P0 未完成项）
