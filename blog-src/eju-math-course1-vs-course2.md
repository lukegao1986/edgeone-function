<p>EJU 的数学分成<strong>コース1</strong>与<strong>コース2</strong>两档。很多同学以为这只是「简单版」和「困难版」的区别，于是凭感觉选一个，结果到了出愿阶段才发现目标学部指定了另一档——分数再高也不作数。这是最典型的一次性错误，而且无法通过重考完全弥补。</p>

## 一、范围差异：コース2 是「コース1 的延伸」

两者的关系不是并列的，而是<strong>叠加关系</strong>。コース1 覆盖的内容大致对应「数学 I + 数学 A」，核心是数与式、二次函数、图形与计量、場合の数と確率、整数の性質等；コース2 在此基础上再叠加「数学 II、数学 B、数学 III」的模块。

| 模块 | コース1 | コース2 |
| --- | --- | --- |
| 数与式、方程式与不等式 | ✅ | ✅ |
| 二次函数 | ✅ | ✅ |
| 图形与计量 | ✅ | ✅ |
| 場合の数と確率 | ✅（含分布与推测） | ✅ |
| 整数の性質 | ✅ | ✅ |
| 指数函数・对数函数 | ❌ | ✅ |
| 三角函数 | ❌ | ✅ |
| 微分・积分 | ❌ | ✅ |
| 数列（本格化） | 基础 | ✅ |
| 向量 | ❌ | ✅ |
| 复数平面 | ❌ | ✅ |

<p>换句话说，<strong>二次函数、概率、整数性质这三块是文理共通的</strong>。这也是为什么文数（コース1）的真题统计对理科生同样有参考价值——高频考点大量重叠，只是コース2 在此基础上还要多准备四个模块。</p>

## 二、难度差异不只是「题更難」

コース2 的难点主要有两处：一是<strong>新增模块本身抽象</strong>，尤其是微分积分与向量；二是<strong>题量更大、时间更紧</strong>，需要更高的计算熟练度。

但反过来，コース1 也不轻松。它在「場合の数」「整数の性質」「図形と計量」上考得很细，这类题的陷阱往往不在计算量，而在<strong>读题与分类是否完整</strong>。用コース2 的思路去刷コース1，容易在「漏情况」上丢分。

## 三、选哪个：看目标学部，不看自己

规则很硬：

<p><strong>目标学部在募集要项里指定哪一档，你就只能考哪一档。</strong>文科类学部（文学、经济、经营、法学等）多指定コース1；理工类学部（工学、理学、医学部相关等）几乎都指定コース2；但也有不少学部两者都接受，或者由考生在报考时选择。</p>

实操建议：

1. **先列目标校清单**，逐校记录数学科目要求，不要凭印象。
2. **混报文理时优先コース2**——它的适用范围更广，多数接受コース1 的学部也接受コース2，反过来不成立。
3. **确认成本**：如果中途从コース1 转コース2，需要补的正是那四个新增模块，工作量不小，越晚转越被动。

## 四、三个常见误解

<p><strong>「コース2 分更高所以更有利。」</strong> 不一定。两科的评分方式不同，且只有目标学部认可的那一档才有效。</p>

<p><strong>「先考コース1 试试水。」</strong> 如果最终目标是理工学部，这一场基本白考，还占用了唯一的两回机会之一。</p>

<p><strong>「文数和理数可以互相替代复习。」</strong> 基础模块可以共通复习，但新增模块必须单独准备，不能靠刷文数真题顶替。</p>

<p>另外提醒一句：科目要求可能<strong>逐学年变动</strong>，往年接受コース1 的学部，今年未必仍然接受。每年出愿前，都要重新下载当年度的募集要項核对一遍，不要沿用去年的结论。</p>

## 小结

选择コース的关键信息只有一个来源：<strong>目标校学部的募集要项</strong>。把它查清楚，剩下的才是备考问题。出题范围请以 JASSO 当年度公布的「出题科目」原文为准。

> 本文所述科目范围为结构性说明，具体出题范围与指定科目请以 JASSO 及各校最新募集要項为准。
