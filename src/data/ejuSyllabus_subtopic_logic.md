# EJU Syllabus Subtopic 分類・修正ロジック

## 分類基準

1. **content にカンマで区切られた2つ以下の短句しかない場合** → 原則として分けない。
2. **content に3つ以上の語句・短句がある場合** → 意味的に近いものをグループ化し、複数の subtopic に分割する。
3. **過度に細分化しない** → 物理的・化学的・生物学的な知識体系に基づき、教育現場で自然な単位になるよう適度に統合する。
4. **bio_6 のデータ不整合を修正** → bio_6_1_1 と bio_6_1_2 の subtopics が bio_9 の生態系内容と誤って重複していたため、正しい内容に修正する。
5. **bio_7 〜 bio_9 の subtopics を新規作成** → これらの chapter は完全に subtopics が未作成だったため、全 topic に subtopics を追加する。
