# EJU 理科考纲 Subtopics (分考点) 划分及自动化处理文档

## 1. 背景与问题

原本的 `/src/data/ejuSyllabus.ts` 文件中，只对 `phy_1_1_1` 手动补充了 `subtopics`，其他所有物理、化学、生物的 `topic` 都缺少分考点。

最开始采用的自动化提取方案仅仅是简单地按逗号（`,`）对大纲中的 `content` 字符串进行分割。这就导致了两个问题：

1. **划分过密且无意义**：例如化学中 `クロム,マンガン,鉄,銅,亜鉛,銀,水銀,及びそれらの化合物の性質や反応,及び用途` 会被强行切分成 9 个细项，其中最后一个 `及び用途` 单独拿出来毫无意义。
2. **关系割裂**：像 `位置,変位,速度,加速度,相対運動` 这样密切相关的概念，应该合理地聚合为 `位置と変位`、`速度と加速度`、`相対運動` 等逻辑块。
3. **数据遗漏**：大纲提取正则未能完全匹配所有数据（例如 `bio_7_1_1` 之后的缺失）。

## 2. 解决方案：引入 LLM 重新划分

为了得到符合人类直觉且具备“独立考查意义”的分考点，我们编写了 `scripts/rewrite_subtopics_v2.js` 脚本，引入 DeepSeek（LLM） 对大纲进行智能清洗与重新聚类。

### 核心步骤：

1. **全量解析大纲**：改进了 Markdown 的正则匹配逻辑，不仅匹配 `#### (1)...` 这一行，还向下读取所有的相关行（直到遇到下一个 `#` 标题），确保生物大纲等末尾部分不再遗漏。
2. **分批调用 LLM**：将提取到的 `topicId -> content` 映射表，以每批 15 个的速度发给 LLM，防止单次请求的 Prompt 过长。
3. **同名合并与容错降级**：
   - 确保 LLM 绝不返回空数组。如果大模型处理失败或内容过短，强制以降级方式（直接将 `content` 本身作为唯一的分考点）写入，杜绝了 `"subtopics": []` 的情况（如 `phy_1_2_3`）。
   - 如果 LLM 返回了多个同名的 subtopic（例如 `phy_1_1_4` 中的多个 `剛体のつり合い`），脚本会在写入前自动按 `name` 进行去重，并将各自的 `aliases` 合并在一起。
4. **深度清理与自动化正则替换**：
   - 因为多次执行遗留的错乱 JSON 结构导致简单的正则无法清理，我们引入了一个专门的深度清洗脚本 `scripts/deep_clean.js`。该脚本按 `"id": "` 分割文件块，精准定位到每个 Topic 的 `"content": "..."` 末尾，然后智能匹配并直接丢弃到下一个 `}` 闭合括号之间的所有脏数据（比如之前累积的各种 `subtopics: []` 嵌套），将其还原成绝对干净的状态。
   - 随后再由主脚本利用正则表达式 `(\\"id\\": ... \\"content\\": \\"...\\")` 匹配出基础信息块，并在其后精确地一次性插入生成好的、排好版的 JSON 节点。彻底根治了重复嵌套的问题。

## 3. LLM 核心 Prompt 设计

在 `rewrite_subtopics_v2.js` 脚本中，我们使用了如下的 Prompt 来指导 LLM：

```text
你是一个 EJU（日本留学試験）理科（物理、化学、生物）题库的知识点分类专家。
我现在有一批各个 Topic（主题）下的原始内容（通常是用逗号分隔的关键词），请你根据这些关键词的内在逻辑关系，将它们重新组合、提炼为更合理、更有概括性的 Subtopic（分考点）。

【划分原则】
1. 必须提供分类，**绝对不能返回空数组**。如果内容非常短，就直接将内容本身作为一个唯一的 Subtopic 返回。
2. **同名合并**：确保返回的 Subtopic 数组中，**name 必须唯一**。如果有几个词最终都指向同一个概括性名称，请把它们合并成一个 Subtopic，将其各自的关键词放进 aliases 数组里。
3. 不要死板地按逗号分割。例如：“クロム,マンガン,鉄,銅,亜鉛,銀,水銀,及びそれらの化合物の性質や反応,及び用途” 不应被切分为 9 个，而应提炼为如：“遷移元素（クロム・マンガン・鉄・銅など）”、“遷移元素の化合物とその性質”、“金属の用途”等具有独立考查意义的分考点。
4. 关系密切的概念应合并。例如：“位置,変位,速度,加速度,相対運動” 可分为：“位置と変位”、“速度と加速度”、“相対運動” 3 个分考点。
5. 每个 Subtopic 需要有：
   - name: 分考点的名称（简明扼要，如“速度と加速度”）
   - aliases: 包含的具体关键词别名数组（如 ["速度", "加速度", "初速度"]）
   - description: 简短描述（如 "速度と加速度に関する問題"）
6. 返回格式必须是严格的 JSON 对象，键为传入的 topicId，值为该 topic 下划分出的 Subtopic 数组。

【输入数据】
(动态注入的 JSON 数据)

【输出格式示例】
{
  "phy_1_1_1": [
    {
      "name": "位置と変位",
      "aliases": ["位置", "変位"],
      "description": "物体の位置や変位に関する問題"
    },
    {
      "name": "速度と加速度",
      "aliases": ["速度", "加速度", "相対運動"],
      "description": "速度、加速度、相対運動に関する問題"
    }
  ],
  "phy_1_2_3": [
    {
      "name": "力学的エネルギーの保存",
      "aliases": ["力学的エネルギーの保存"],
      "description": "力学的エネルギーの保存に関する問題"
    }
  ]
}

请直接返回 JSON 数据，不要包含任何 markdown 代码块标记或其他说明文字。
```

## 4. 执行结果

执行 `node scripts/rewrite_subtopics_v2.js` 后：

- **物理**、**化学**、**生物** 三科的近百个 Topic 已全部被重新划分为合理的 Subtopic。
- 生物大纲缺失的部分（如 `bio_7_1_1` 之后的神经系统、受容器、中枢神经等）已被完整修复并加入。
- 修复了空数组和同名分考点未合并的问题。
- 所有生成的分考点数据均已正确写入 `src/data/ejuSyllabus.ts`。

未来如果大纲有更新，只需更新 `docs/考试大纲/理综大纲/` 目录下的 `.md` 文件，并重新运行该脚本即可。
