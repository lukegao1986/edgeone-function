# 题库批量上传工具

这个工具可以帮助你将整理好的 JSON 格式题库，一键批量上传到腾讯云的 MySQL 数据库中。
工具支持自动去重：如果发现题库中已经有相同的题目 ID，它会自动更新该题目的内容，而不会报错。

## 目录结构
```text
scripts/uploader/
├── upload.js          # 上传执行脚本核心逻辑
├── README.md          # 本使用说明
└── data/              # 存放你需要上传的题库 JSON 文件的目录
    └── sample.json    # 示例题库文件
```

## 准备工作

在运行脚本之前，你需要确保已经准备好了题库文件。
1. 在 `data/` 目录下，创建一个 `.json` 结尾的文件（例如 `chem_chapter1.json`）。
2. 按照以下严格的格式填入题目：

```json
[
  {
    "id": "chem-001",
    "subjectId": "science",
    "category": "化学",
    "stem": "在标准状况下，将 22.4L 氯气通入水中的反应如下图所示：\n\n![实验装置](https://你的腾讯云COS图床链接/image1.png)\n\n请分析产物：",
    "options": [
      "A. 反应完全",
      "B. 反应可逆",
      "C. 生成沉淀",
      "D. 发生爆炸"
    ],
    "correctIndex": 1,
    "explanation": "因为氯气溶于水是可逆反应，所以选 B。"
  }
]
```

### 字段详细说明：
- **`id`** (必填): 题目的唯一标识符。建议使用拼音缩写+数字，如 `chem-001`。
- **`subjectId`** (必填): 科目 ID。目前系统支持：`japanese`(日语), `bunso`(文综), `math1`(数学1), `math2`(数学2), `science`(理科)。
- **`category`** (必填): 题目的具体分类，如 `化学`、`物理`、`读解`。
- **`stem`** (必填): 题干。**支持插入 Markdown 格式的图表链接！** 你只需要先把图片上传到图床（如腾讯云 COS），然后用 `![描述](链接)` 语法贴在这里。
- **`options`** (必填): 包含四个选项的数组。
- **`correctIndex`** (必填): 正确选项的数字索引。`0` 代表 A，`1` 代表 B，`2` 代表 C，`3` 代表 D。
- **`explanation`** (选填): 详细解析。同样支持插入图床链接和 Markdown 语法。

## 如何运行上传

打开你电脑（或者 VS Code）的终端，进入到项目根目录（`edgeone-ex` 文件夹下）。

### 1. 确保安装了数据库驱动
如果你之前没安装过，先执行一次：
```bash
npm install mysql2
```

### 2. 执行上传命令
命令格式为：`node scripts/uploader/upload.js [文件名]`

如果你想上传 `data/` 目录下的 `sample.json`，直接执行：
```bash
node scripts/uploader/upload.js sample.json
```

如果运行成功，终端会输出类似以下的日志：
```text

✅ 成功读取 JSON，共找到 1 道题目。

🔗 正在连接腾讯云数据库...
✅ 数据库连接成功!

📤 开始上传数据...
  ✔️ [成功] 题号: chem-001

🎉 上传完成!
📊 统计: 成功上传 1 题，失败 0 题。
```

## 常见问题与解答

**Q: 上传失败，提示 "数据库连接失败"？**
A: 请检查你的电脑网络是否正常，并登录腾讯云控制台确认你的轻量数据库是否处于运行状态，且没有被防火墙拦截当前网络的 IP。

**Q: 发现传错了一道题，怎么修改？**
A: 直接在你的 json 文件里把那道错题的内容改掉（**不要改 id**），然后重新运行一遍 `node scripts/uploader/upload.js`。系统会根据 `id` 自动覆盖更新旧的错误内容。

**Q: 我可以用 Excel 整理吗？**
A: 可以，但你需要先用网上的免费工具（搜索 "Excel to JSON"），把你整理好的 Excel 表格转换成上面要求的 JSON 数组格式，再放进 `data/` 目录下运行。
