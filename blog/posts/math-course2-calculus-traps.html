数学コース2：微积分常见陷阱与避坑指南

📅 2026-10-16 ⏱ 约 12 分钟 👁 1620 次阅读

在 EJU 数学コース2（理科数学）中，微分与积分部分的分值约占全卷的三分之一，是拉开档次的核心模块。它以「数学III」的微积分为主，涵盖极限、导数、函数性质、各種の積分法、面积与旋转体体积等内容。理科生如果只背公式而不厘清适用条件，往往会出现一种典型现象：会算但不得分。

所谓「会算」，是指机械地套用求导、积分公式时能得到一个数值；所谓「不得分」，是指这个数值在阅卷标准下根本不成立——因为前提不满足、定义域越界、上下限没有同步、或者把定积分的值与几何面积混为一谈。EJU 的题目不长，但每一步都暗藏条件，一旦条件不成立，后面整段推导全部作废。下面按六个高频陷阱逐一拆解，并附 12 条速查表和一份做题检查清单。

陷阱一：极限的四则运算滥用

极限的加减乘除法则只有在参与运算的每一部分极限都存在，且做除法时分母的极限不为 0 时才成立。很多同学看到式子就直接拆开分别求极限，例如要求 lim(x→0) (sin x)/x² · (1 + 1/x) 这类复合形式时，若直接把它拆成两项分别求极限，就会得到「∞ − ∞」或「有穷 × ∞」的错误结论。

举个典型例子：求 lim(x→0) (1/x − 1/sin x)。两部分各自的极限都不存在（都是 ∞），因此不能写成两项之差分别取极限，而必须通分后合并：

lim(x→0) (1/x − 1/sin x) = lim(x→0) (sin x − x) / (x·sin x)

此时分子分母同为 0，构成 0/0 型，才能继续用洛必达或等价无穷小展开。记住：先判断各部分极限是否存在，再决定能否拆分，这是四则运算法则的前置条件。

陷阱二：洛必达法则的适用条件

洛必达法则并不是「见到分式就上下求导」。它同时要求三个条件：第一，原极限必须是 0/0 或 ∞/∞ 的不定式；第二，分子分母在其去心邻域内可导（除个别点外）；第三，求导后新分式的极限存在或为 ∞，若新极限振荡不存在，则法则是失效的，不能反推出原极限不存在。

⚠️ 用洛必达之前，务必先代入验证未定式类型。像 lim(x→0) (x + 1)/x 这种直接就是 ∞ 型确定的极限，套洛必达只会越算越乱；而 lim(x→∞) (x + sin x)/x，求导后为 (1 + cos x)，振荡无极限，此时应改用夹逼或分子分母同除 x。

另外，洛必达可以连续使用，但每次使用后都要重新验证是否仍是未定式，一旦不再是 0/0 或 ∞/∞ 就必须停下来直接代入。

陷阱三：导数符号与单调性

很多同学习惯把 f'(x) = 0 直接当成极值点，这是最普遍的错误。导数等于 0 只是驻点，是取得极值的必要条件而非充分条件。必须进一步判断 f'(x) 在驻点左右是否变号：由正变负为极大值，由负变正为极小值，符号不变（如 y = x³ 在 x = 0）则不是极值点。

此外要注意「极值点 vs 端点」的区别：在闭区间 [a, b] 上求最值时，除了比较所有驻点和不可导点的函数值，还必须计算两个端点的函数值 f(a) 与 f(b)。很多题目最大值恰好落在端点，漏算就会丢掉正确答案。含参数的单调性讨论中，还要注意导数等于 0 的点是否真的落在讨论区间内，落在区间外的相信无意义。

陷阱四：定积分换元时上下限忘记同步

定积分换元后，积分变量从 x 变成了 t，积分上下限也必须一起换成对应 t 的值，否则整个结果全错。例如计算：

∫₀² x·√(x² + 1) dx

令 t = x² + 1，则 dt = 2x dx，即 x dx = dt/2。此时上下限要同步替换：当 x = 0 时 t = 1，当 x = 2 时 t = 5。正确写法是：

∫₀² x·√(x² + 1) dx = ∫₁⁵ (1/2)√t dt = (1/3)·t^(3/2) ∣₁⁵ = (1/3)(5√5 − 1)

错误写法是换元后仍沿用原来的 0 和 2 上下限，得到的值完全是另一回事。若懒得换上下限，也可以先求原函数再回代 x，但中途绝不能混用两种变量。

陷阱五：面积与定积分值的区别

定积分本身是一个有向的代数值：曲线在 x 轴下方时，该段定积分为负数；而几何面积恒为正。若题目问的是「曲线与 x 轴围成的面积」，就必须找出曲线与 x 轴的交点，把积分区间分段，对 x 轴下方的部分取相反数后再相加。

例如求 y = x² − 1 与 x 轴在 [−2, 2] 上围成的面积。直接算 ∫₋₂² (x² − 1) dx 会得到 4/3，这是错误的，因为 [−1, 1] 区间曲线在轴下方。正确做法是分段：

S = ∫₋₂⁻¹ (x² − 1) dx + ∣∫₋₁¹ (x² − 1) dx∣ + ∫₁² (x² − 1) dx

另外，若求两曲线之间的面积，要先比较两条曲线在该区间内的大小关系，用「上减下」再积分，交点处需拆区间。

陷阱六：参数方程与隐函数求导

参数方程 x = x(t)、y = y(t) 求 dy/dx 时，用的是链式法则的合成结果，不是分子分母分别对 x 求导：

dy/dx = (dy/dt) / (dx/dt)，其中 dx/dt ≠ 0

必须保证 dx/dt ≠ 0，否则切线可能竖直、导数不存在，此时应单独讨论该点。二阶导数则要对 dy/dx 再关于 t 求导，再除以 dx/dt，即 d²y/dx² = (d/dt(dy/dx)) / (dx/dt)，不能直接把 dy/dx 对 x 二次求导。

隐函数 F(x, y) = 0 求导时，对 y 求导要乘上 dy/dx（因为 y 是 x 的函数），再把 dy/dx 的项整理到一边。隐函数求导也常用于含 e^y、ln y 的场合，注意对数求导时定义域为正。

做题检查清单

  1. 写极限前，先代入判断是否为未定式，并确认能否拆分。
  2. 使用洛必达前，逐条核查「未定式 / 可导 / 新极限存在」三个条件。
  3. 求单调性与极值时，画导数符号表，标注驻点与不可导点。
  4. 闭区间求最值，逐一计算并比较所有候选点与端点的函数值。
  5. 换元积分后立刻改上下限，或明确回代原变量的步骤。
  6. 求面积先找交点、分段，确认每段取正后再求和。
  7. 参数方程求导前，检查 dx/dt 是否为 0，单独处理竖直切线。
  8. 求导与积分完成后回看定义域，检查 ln|x| 的绝对值与分母不为零。

最后送上一个必须烂熟于心的公式。无论是定积分计算还是面积、体积问题，牛顿-莱布尼茨公式都是核心桥梁：

∫ₐᵇ f(x) dx = F(b) − F(a)，其中 F'(x) = f(x)

把它与旋转体体积公式 V = π∫ₐᵇ y² dx 一起记牢：一个负责把积分算出来，一个负责把几何量翻译成积分。条件清楚、步骤规范，微积分部分的分数就稳了。

📌 本文要点回顾
  1. 极限四则运算有前提——各部分极限均存在、且作除法时分母极限不为 0，才能拆开分别求。
  2. 洛必达的三条件：未定式、分子分母可导、求导后新极限存在，缺一不可。
  3. f'(x)=0 只是驻点，必须判断左右是否变号才能断定极值；闭区间最值别忘了两端点。
  4. 换元必同步上下限；求面积要按交点分段、把 x 轴下方部分取相反数。
  5. 参数方程求导用 (dy/dt)/(dx/dt)，且必须保证 dx/dt ≠ 0。
