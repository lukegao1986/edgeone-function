物理专题

理科物理：力学综合题的「三步拆解法」

📅 2026-10-12 ⏱ 约 15 分钟 👁 1860 次阅读

引言：公式都会，为什么还是丢分

在 EJU 理科的物理卷里，力学（運動とエネルギー、力のつりあい）长期占据约三分之一的分值，而且最容易以「斜面 + 摩擦 + 弹簧」「碰撞 + 能量」这类多过程综合题的形式出现。很多同学的复习方式是背公式：牛顿第二定律、动能定理、动量守恒，一条不落。但一到综合题就卡住——不是不会公式，而是不知道该用哪一条、按什么顺序用。

综合题的失分点往往集中在一开始：受力没画全，漏掉摩擦力或把方向搞反；过程没拆开，把几段性质完全不同的运动当成一段；到最后又在「用动能定理还是动量守恒」之间反复横跳，白白耗掉考试时间。下面给出一个可以机械执行的三步框架，让力学综合题从「靠感觉」变成「按流程走」。

三步法总览

任何一个力学综合题，都可以拆成三步，每步都有明确的输出物：

  1. ①受力分析——隔离研究对象，逐一确认它受到的每一个力。输出物：受力图 + 沿各坐标轴写出的方程（含 f = μN、F = kx 等辅助关系）。
  2. ②运动分析——判断每一段运动的性质（匀速、匀变速直线、平抛/斜抛），选对应的运动学公式。输出物：加速度 a 与所属运动模型，以及各段的速度、位移关系。
  3. ③能量/动量选择——当题目涉及「求位移」「求末速度」「碰撞后速度」「摩擦生热」时，优先绕过运动学，用能量或动量关系一步到位。输出物：一条守恒式或动能定理式。

顺序不能颠倒：受力分析决定了每一步有哪些力做功，运动分析决定了能量方程里的位移该怎么写。跳过第一步直接列能量方程，几乎一定会漏掉摩擦力做的功。

第一步：受力分析

核心方法是隔离法：把要研究的物体单独拿出来（哪怕它正与其他物体接触），只画「别的物体对它的力」。按固定顺序逐一确认，可以有效避免遗漏：

  1. 重力 mg，竖直向下，永远存在；
  2. 支持力/弹力 N，垂直于接触面，指向被压的物体；
  3. 摩擦力 f = μN，沿接触面，方向与相对运动（或相对运动趋势）相反；
  4. 张力，沿绳方向，指向绳的收缩一侧；
  5. 弹簧弹力 F = kx，方向由形变方向决定，x 是形变量而非弹簧全长。

摩擦力是最容易出错的。判断顺序应该是：先看物体是否处于平衡（或给定运动状态），再决定是静摩擦还是动摩擦。如果物体静止，接触面上的是静摩擦 f_s，它的大小由平衡条件反推，不能直接用 f = μN；只有当物体已经发生相对滑动时，才可用 f = μN 计算动摩擦。常见的翻车方式是：先默认「它是动摩擦」，算完才发现物块其实静止，整道题作废。

提示列式前先问一句：这个物体处于平衡吗？已知静止或匀速 → 合力为零，用平衡方程；已知有加速度 → 用牛顿第二定律。这一步决定了后面所有方程的形式。

第二步：运动分析

受力分析完成后，加速度 a 一般就确定了（a = F_合 / m）。接下来判断每一段运动属于哪种模型，套对应公式即可。

最常见的是匀变速直线运动，三个公式覆盖全部情况：

v = v₀ + at
x = v₀t + ½at²

以及不含时间的位移–速度关系：

v² − v₀² = 2ax

另一个高频模型是抛体运动，处理方式是把运动分解到两个互相垂直的方向上，各自独立：水平方向匀速（v_x = v₀cosθ、x = v₀cosθ·t），竖直方向匀变速（v_y = v₀sinθ − gt、y = v₀sinθ·t − ½gt²）。分解之后，每个方向都退化成上面三种直线运动，问题立刻降级。

第三步：能量与动量如何选择

能用运动学硬解，不代表应该硬解。当题目里出现「求位移」「多段运动」「碰撞」这些关键词时，能量或动量往往能一步到位。选择依据如下表：

题目特征优先选择理由
有摩擦、求滑行位移动能定理摩擦力做功 = −fx，位移可直接解出，无需过程细节
碰撞 / 爆炸 / 反冲动量守恒作用时间极短，内力远大于外力，动量守恒成立
求时间或求加速度牛顿定律 + 运动学能量方程不含时间，求 t、a 必须回到动力学
含弹簧 / 有高度变化且无摩擦机械能守恒只有重力与弹力做功，动能与势能相互转化
已知冲量或求平均作用力动量定理冲量等于动量变化，适合处理短时冲击

一句话记住：求「位移、速度大小」用能量，求「时间、方向」用动力学，涉及「碰撞」用动量。

完整例题：斜面下滑 + 弹簧压缩

场景：质量 m 的物块，从高度 h、倾角 θ 的光滑斜面顶端由静止下滑，斜面底端与水平面平滑连接；水平面粗糙，动摩擦因数为 μ；斜面底端到弹簧自由端的水平距离为 L；弹簧劲度系数为 k。物块最终压缩弹簧。重力加速度为 g。

力的分析要点（逐条列出）：

  • 斜面上：受重力 mg（竖直向下）与斜面支持力 N₁（垂直斜面向上）。斜面光滑，无摩擦力。
  • 沿斜面分解：重力沿斜面向下的分量为 mg sinθ，垂直斜面的分量为 mg cosθ。
  • 水平面上：受重力 mg、竖直向上支持力 N₂ = mg、水平方向与运动反向的滑动摩擦力 f = μmg。
  • 接触弹簧后：除上述力外，增加与运动反向的弹簧弹力 kx（随压缩量增大而增大），摩擦力仍为 μmg。

各阶段运动性质：阶段一（斜面）——初速度为零的匀加速直线运动，沿斜面向下的加速度 a = g sinθ；阶段二（水平面滑向弹簧）——水平方向匀减速运动，加速度大小为 μg；阶段三（压缩弹簧）——加速度大小不断增大的变减速运动，最终速度减为零。正因为阶段三是变减速，运动学公式不再适用，必须改用动能定理。

第（1）问：物块在斜面上的加速度 a，以及滑到斜面底端的速度 v。

沿斜面方向由牛顿第二定律：

mg sinθ = ma  ⟹  a = g sinθ

斜面光滑，只有重力做功，机械能守恒（等价于用运动学求解）：

mgh = ½mv²  ⟹  v = √(2gh)

注意结果 v 中不含 θ：只要下滑高度相同、斜面光滑，到底端的速度大小就相同，这是很好的自检点。

第（2）问：物块滑行距离 L 到达弹簧自由端时的速度 v₁。

从斜面底端到接触弹簧，重力与支持力不做功，只有摩擦力做负功，由动能定理：

½mv₁² − ½mv² = −μmgL

代入 v² = 2gh，解得：

v₁ = √(2gh − 2μgL)

能到达弹簧的条件是根号内为正，即 h > μL；若 h = μL，物块恰好在弹簧自由端停下。

第（3）问：弹簧的最大压缩量 x。

取「物块接触弹簧到速度减为零」这一过程。其间摩擦力做负功 −μmgx，弹簧弹力做负功 −½kx²，动能由 ½mv₁² 减到 0，由动能定理：

0 − ½mv₁² = −μmgx − ½kx²

整理并把 ½mv₁² = mgh − μmgL 代入：

½kx² + μmgx = mgh − μmgL

这是关于 x 的一元二次方程 kx² + 2μmgx − 2mg(h − μL) = 0，取正根：

x = [ −μmg + √( μ²m²g² + 2kmg(h − μL) ) ] / k

用 μ = 0（水平面也光滑）验证，可退化为 x = √(2mgh / k)，与纯机械能守恒的结果一致。

五个常见错误

  1. 漏掉摩擦力方向或大小：摩擦力方向与相对运动方向相反，而非与「运动方向」相反；物块在斜面上上滑与下滑时，摩擦力方向是相反的。
  2. 把静摩擦当动摩擦：物块静止时 f_s ≤ μN，其大小由平衡条件求出，直接代 f = μN 往往偏大。
  3. 有摩擦时误用机械能守恒：只要接触面粗糙、存在滑动摩擦，机械能就不守恒，必须改用动能定理，把摩擦力做的功写成 −fx。
  4. 动量守恒方向未取正方向：动量是矢量，列守恒式前必须先规定正方向，各速度带符号代入，否则一维碰撞也会算错。
  5. 单位未统一：cm 要换算成 m、g 要换算成 kg，k 的单位是 N/m。单位不统一是「公式对但结果错」的头号原因。

把这三步固化成习惯：先隔离受力、再判断运动、最后择优使用能量或动量，力学综合题就会从「碰运气」变成「走流程」。下一步的刻意练习方式是：拿到题先只写第①步的受力分析，强迫自己不上手算，坚持两周，选择题的失分会有明显下降。

📌 本文要点回顾
  1. 顺序不可颠倒：先隔离受力、再判断运动、最后择优使用能量或动量。
  2. 受力分析用隔离法，按「重力→支持力→摩擦力→张力→弹簧弹力」固定顺序逐一确认，避免遗漏。
  3. 静摩擦不能直接代 f = μN；先判断物块是否平衡，静止时摩擦力由平衡条件反推。
  4. 运动分析看模型：匀变速直线三个公式 / 抛体运动按两个垂直方向分解。
  5. 选择依据：求位移与速度大小用能量，求时间与方向用动力学，涉及碰撞用动量。
  6. 单位统一：cm→m、g→kg 是「公式对但结果错」的头号原因。
